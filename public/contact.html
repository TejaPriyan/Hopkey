Get help or report an issue

Email teja1616150@gmail.com for website feedback, privacy questions or a reproducible problem. You can also use the project’s GitHub issues for a public bug report.

Include the page or mode, browser and device, what you expected and the steps that produced the problem. GitHub issues are public: remove passwords, personal files, active transfer codes and confidential URLs before posting. A small harmless example is usually enough.

Messages sent by email or through GitHub are processed by those services and received by the developer. The website does not offer a separate support ticket account or promise a response deadline.
